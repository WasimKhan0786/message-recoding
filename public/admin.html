Storage Architecture & Security Notice

🔒 Private Filebase S3 Bucket Audio recordings are stored in a private Filebase S3 bucket. Raw storage URLs, AWS credentials, and IPFS keys are never sent to the client browser.
⚡ HTTP 206 Range Streaming Playback streams dynamically through the AudioFlow server with HTTP Range requests. Download controls are suppressed on public player pages.
🛡️ Security Transparency While direct downloads and raw links are strictly hidden, client-side browser streaming cannot guarantee 100% prevention of external analog recording.
